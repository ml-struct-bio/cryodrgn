Load covariate from .pkl

Choose a numpy array saved as .pkl with one row per particle (length must match the plotted particle count). Use a 1-D array for one covariate or a 2-D array for several columns. Numeric values use continuous colouring; text labels (or other non-numeric values) are always treated as discrete colour categories.
